PlantCare v7 Expanded Care
Upload index.html, manifest.webmanifest, service-worker.js and both PNG icons to your GitHub Pages repository root.
This release adds a larger curated plant catalog, bloom expectations, water quality, pot/soil/fertilizer options, soil pH testing, winter return notes and a photo reference in health checks.
IMPORTANT: This version DOES NOT include genuine AI image analysis. Photos are local previews only; health checks analyze questionnaire answers. To enable AI scanning requires a secured backend and vision model/API, not a public API key in GitHub Pages.
Plant suitability, bloom and hardiness data are broad species-level estimates; check cultivars, pet toxicity and local growing conditions before relying on them.
